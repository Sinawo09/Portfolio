# Sinawo Mthiyane Portfolio

A responsive personal portfolio for Sinawo Mthiyane, a junior web developer. The site presents her background, skills, projects, education, work experience, certificates, and contact options.

## Features

- Responsive navigation and page sections
- Project portfolio with links to live applications
- Education, work experience, and certificate galleries
- Downloadable CV
- Interactive chatbot
- Contact form

## Built With

- HTML5, CSS3, and JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts

Bootstrap, Font Awesome, and Google Fonts are loaded from external CDNs, so an internet connection is needed for those assets.

## Run Locally

This is a static site and does not require a build step or package installation.

1. Clone the repository and open its folder.
2. Open `index.html` in a browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension to serve `index.html` locally.
